# Data-Warp API

Data-Warp API is a FastAPI-based backend service for managing a DuckDB database. It exposes endpoints for listing available tables, retrieving table schemas, executing SQL queries with pagination, and previewing table data. The API also features interactive Swagger documentation for easy testing and integration.

## Features

- **List Tables**: View available tables in the DuckDB.
- **Schema Retrieval**: Get columns and types for a given table.
- **SQL Query Execution**: Run SQL queries with pagination (supports arbitrary queries).
- **Data Preview**: Quickly preview the first n rows of a table.
- **Interactive Documentation**: Swagger UI is available for testing all endpoints.

## Installation

Ensure you have Poetry installed. Then clone the repository and install dependencies as follows:

```bash
git clone https://github.com/your-username/data-warp-api.git
cd data-warp-api
poetry install
```

## Configuration

API configuration is managed with pydantic-settings. By default, the DuckDB database is set in `backend/api/core/config.py` as:

```python
DUCKDB_PATH: str = "data/duckdb.db"
```

You can override this value via an environment variable or by using a `.env` file in the project root.

## Running the Application

### Seed the Database

Before running the application, seed your database by executing the script:

```bash
poetry run python scripts/seed_database.py
```

### Start the API

You can run the API via Uvicorn:

```bash
poetry run uvicorn run:app --reload
```

The API will be accessible at http://127.0.0.1:8000.

## API Endpoints

### List Tables

- **Endpoint**: `GET /tables/`
- **Purpose**: Returns a JSON array containing all tables available in the DuckDB.
- **Response Example**:
  ```json
  {
    "tables": ["sales_data", "events_stream"]
  }
  ```

### Get Table Schema

- **Endpoint**: `GET /tables/{table_name}/schema`
- **Purpose**: Retrieves the schema (column names and data types) for the specified table.
- **Response Example**:
  ```json
  {
    "columns": [
      {"name": "id", "type": "INTEGER"},
      {"name": "created_at", "type": "TIMESTAMP"},
      {"name": "amount", "type": "FLOAT"}
    ]
  }
  ```

### Execute SQL Query with Pagination

- **Endpoint**: `POST /query/`
- **Purpose**: Executes an SQL query provided by the user with pagination parameters.
- **Request Example**:
  ```json
  {
    "sql_query": "SELECT * FROM sales_data WHERE amount > 100",
    "page": 1,
    "per_page": 50
  }
  ```
- **Response Example**:
  ```json
  {
    "columns": ["id", "created_at", "amount"],
    "rows": [
      [1, "2024-01-01 12:00:00", 153.20],
      [2, "2024-01-02 13:20:00", 201.10]
    ]
  }
  ```

### Preview Table Data

- **Endpoint**: `GET /preview/{table_name}?limit=100`
- **Purpose**: Quickly preview the first n rows of the specified table.
- **Response Example**:
  ```json
  {
    "columns": ["id", "created_at", "amount"],
    "rows": [
      [1, "2024-01-01 12:00:00", 153.20],
      [2, "2024-01-02 13:20:00", 201.10]
    ]
  }
  ```

## Swagger Documentation

Interactive API documentation is automatically generated by FastAPI and can be accessed at:

- **Swagger UI**: http://127.0.0.1:8000/docs
- **Redoc**: http://127.0.0.1:8000/redoc

These interfaces allow you to visualize all endpoints, send test requests, and view responses.

## Postman Examples

For easier integration, here are some sample Postman requests:

- **List Tables**:
  - Method: GET
  - URL: http://127.0.0.1:8000/tables/

- **Get Table Schema**:
  - Method: GET
  - URL: http://127.0.0.1:8000/tables/sales_data/schema

- **Execute SQL Query**:
  - Method: POST
  - URL: http://127.0.0.1:8000/query/
  - Body (JSON):
    ```json
    {
      "sql_query": "SELECT * FROM sales_data WHERE amount > 100",
      "page": 1,
      "per_page": 50
    }
    ```

- **Preview Table Data**:
  - Method: GET
  - URL: http://127.0.0.1:8000/preview/sales_data?limit=100
